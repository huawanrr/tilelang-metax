# 928 四/八份 PV 累加器

packed S8 按所选块序号将 PV 分别累加到4/8份 FP32 输出，最后相加归一化。
每个块的 mask、加载和概率计算不变，累加次序改变。六个候选形状参考检查
通过。八份版本在 case81 明显回退，不采纳。

24.20→26.00us。32次夹测复现大网格约1.9%的信号，小网格约0.91/0.93x。

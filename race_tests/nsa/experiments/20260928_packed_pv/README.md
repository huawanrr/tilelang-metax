# 928 S1 打包 KV + 分段 PV

研究版，没有生成提交文件。以 `../20260927_next/selected.py` 为固定基线，
新增单块 packed attention，实验只分派 S1/D128/BS32/G16/threads64。
每次调用重新打包 K/V，公开 `run_kernel` 总耗时包含这次打包。

QK 直接从 packed K fragment 计算。PV 输出宽度分别为 32/64/128，V 只保留
对应宽度的 fragment；第一段 V 在 QK 前同步读取，后续段在使用前读取。
各宽度比较概率前置归一化与输出后置归一化。没有 shared K/V 或异步复制。

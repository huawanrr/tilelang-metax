# 928 转置 QK/PV

QK 改为 K×Qᵀ，PV 改为 Vᵀ×P，输出 fragment 按 D×G 布置，让相邻线程
沿输出的特征维写回。概率经额外的共享内存 tile 转换布局，分别测试前置和
后置归一化。两个候选在 oj6/case69/case83 的6个参考检查通过。

结果拒绝：oj6 基线134.16us，候选189.99/190.76us；case69 78.64→103.33/
104.47us；case83 29.70→37.08/36.43us。额外转换与共享存储成本没有被连续
输出写回抵消。原始四轮交替计时见 `transposed.json`。未修改提交文件。

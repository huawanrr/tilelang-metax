后续筛选与合并结果（2026-09-30）：

- `single_wave_full.json`：109 例比较单 wave 同步和共享 Q 变体，均先对照独立参考。

  wave barrier 分别保护 Q RAW、Q/K WAR、K RAW、K/V WAR 和 V RAW。
  合并版的复用范围为 256 < grid <= 2048；2560 < grid <= 4096 使用并行暂存。
- `pv_bracketed.json`：PV32 + 线性 V + 显式同步，四例各 40 次 A/B/A 长测，
  每图 500 调用。oj6 约 107.65 -> 104.36 us，case69 约 61.66 -> 58.97 us；
  所有候选样本均满足 1% 基线漂移阈值，同源控制约 1.000x。
  `pv_sync_families.json` 的 12 个邻近形状也有收益，合并范围扩展为 grid >= 128。

  合并版使用早归一化和自动 barrier 插入，额外 wave 版本没有稳定优势。

# 完整块读取初版（研究记录）

本目录保留第一次整合的源码和不利性能样本。候选后续收敛到
`../20261002_blocks_v2`，本目录不是最终推荐提交。

成对读取采用同地址TileLang block视图和每lane四次uint32读取，不增加数据准备或
kernel启动。保留D32 v1的41个非分派函数，仅新增builder与统一分派。

`short_multiseed.json`：12种形状、3种子、每组24次A/B/A、每图500调用。
D128短序列均加速；D64/T32的一种子为0.99301×，D64/T64三个种子分别为
0.99031/0.98827/1.02330×。后续版本将D64整个seq_len<128区间保留原路径。

`d64_short_boundary.json`：8个邻近形状、3种子，同样保留所有尝试。
D64/T128/B32仍有单种子0.98988×，另两个为1.00823/1.03181×；这是边界限制，
不能将其抹去或声称对任意输入都提速。96/112长度的正收益也保留，但未在最终版启用。

完整块、lane归属与共享地址的CPU证明见`layout_proof.json`。初版源码保持原哈希，
没有覆盖本目录的测量；最终完整验证与全量性能以v2目录为准。尚无新OJ成绩。

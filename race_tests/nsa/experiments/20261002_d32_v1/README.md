在 10.2 final 的基础上，默认 S1/D32/BS16/G16/64 线程按 `grid=B*H*seq_len` 选择：

- grid≤512：沿用 direct-K 布局与同步，先验证 block 编号再形成地址。

- H1 且 1024≤grid≤4096：保留原 K shuffle 与 wave 同步，改写索引验证。
- 其他形状和显式调参保持 10.2 原路径。两种公开接口共用 `_get_kernel`。

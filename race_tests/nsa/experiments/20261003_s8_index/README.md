# S8 索引与加载调度研究（2026-10-03）

基线为正式88.29分的 `../20261002_mid_v1`。所有改动限于已有默认S8、grid≥4096
的两种合并输出builder；每次调用的K/V打包计入测量。GPU实验串行执行，独立FP32参考关闭TF32。

首轮6形状、4轮交替、每图200调用、每轮7次采样均正确：

| 方案 | 几何平均加速比 | 结论 |
|---|---:|---|
| 展开两轮lookahead循环 | 0.99715457× | 不采用 |
| 先检查block编号再形成地址 | 1.00196582× | 幅度小且有回退，暂不采用 |
| 两者合并 | 1.00091203× | 不采用 |

`screen.json`保留全部轮次和设备源码。oj12的基线和显式展开版本，device .text
长度和SHA256完全相同：编译器已完成相同展开。原始资源记录和机器码比较位于
`screen_resources_oj12.json`、`screen_machine_code_oj12.json`。
block编号检查将oj12的streg从52降到40，但mtreg仍为103，没有相应速度收益；
grid8192的四累加器路径mtreg为127。因此继续测试较小的同步K提前读取深度，
以及Q提前读取、V0提前读取的调度方案。

本目录为研究代码，尚无可提交发布。基线和所有未采用样本保留。

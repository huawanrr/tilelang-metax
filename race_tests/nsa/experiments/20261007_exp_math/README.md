## 最终改动

在现有 S8/D64/BS16 大网格路径上，把 `exp2(min(x * scale_log2, 15))`
改为 `exp(min(x * (scale_log2 * ln(2)), 15 * ln(2)))`。
MACA 的 `exp2f` 带有数学库下溢处理，`expf` 在原有 fast-math 设置下使用 builtin。
初始指数探针的 oj12 寄存器记录为 103→94，无 spill；最终候选对应缓存记录也是 94。
未新增数学编译选项，S1 保留原来的 exp2 实现。

概率和输出片段的 FP32→FP16 转换改为每个线程对其实际拥有元素的标量转换。
原成对转换会调用显式舍入辅助函数；标量转换使用 MACA 已有的 fast half conversion。
概率转换单独探针的机器码中，GET_HWREG 为 48→16，SET_HWREG 为 96→32，
转换次数、指数及 MMA 运算保持；这些计数属于单独探针，不是对最终内核计数的推断。

新增路径同时在乘 BS 前限制 S8 原始块号，避免无效大索引溢出；
零/负 scale 在指数之后重新应用有效元素掩码。正 scale 保留实际计时的计算体。
无额外 FP16 舍入步骤，无额外 kernel 启动，打包每次读取当前 K/V。

默认参数启用范围（`grid = B * H * T`，`G = HQ / H = 16`）：

| 路径 | 范围 |
|---|---|
| S8 packed output | D64、BS16、grid ≥ 4096 |
| S1 packed Q/O | D128、BS32、grid ≥ 1024 |
| S1 coalesced blocks | 完整 BS16 块；D64 要求 T ≥ 128 且 grid ≥ 2304；D128 要求 grid ≥ 1280 |

沿用已有范围，不按用例编号、输入内容或计时阶段分派。
原有 44 个非分派函数的 AST 保持，新增五个 `_mathcast` 函数。
非默认调参回退原 builder；`q_preload`、`q_frag` 等显式值与默认 `None`
在参数解析前区分，并以新缓存键防止混用。两个公开接口签名保持。

## 保留的未采用实验

全路径替换自然指数在部分 S1 上回退，因此只在最终 S8 范围使用。
half-exp、指数下限/多项式近似、额外 Q/K 半精度预缩放、S8 lookahead/累加器调参、
分组 QK/probability 调度、延后 mask、寄存器限额 80/88/96 均未形成可采用的整体收益。
其中预缩放还引入额外 FP16 舍入，寄存器限额存在明显回退。
仅调整 coalesced_width=1 的转换生成相同设备码；部分 Parallel 转换布局及显式布局推断失败。
这些失败日志、负计时和生成器保留，不因最终版本采用其他方案而删除。

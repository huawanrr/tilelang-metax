# 大 S8 的 Q 寄存器驻留（2026-10-07）

`../20261007_resume/release_v1` 已冻结，后续实验在此隔离进行。
正式基线仍为 88.29；目标 89 仍待 OJ 结果确认。

大 S8 的原实现让 Q fragment 在整个选中块循环期间存活。
本轮尝试在 shared 中保留 Q，每次 QK 只读取当前所需的部分，减少同时占用的
寄存器；代价是重复的 shared 读取。比较半块/完整 fragment 重载，以及直接
写 shared / 显式连续 Q staging 四种方案。Q 写入后的 RAW 等待和输出共享
缓冲区复用前的 WAR 等待都保留显式 wave 同步。

另比较 4/8 个 int32 的连续 BlockIndices 向量读取，确认初始索引指令是否还有收益。
这六个实验仅改写现有两个大 S8 builder；公开分派、每次输入打包与其他函数 AST
均保持基线。尚不能据此作为发布版本。

`screen.json` 使用独立 FP32 参考和公开 run_kernel 的 A/B/A 计时，
包含每次 packing；共同图内存池，同源控制和全部原始样本均保留。
四个形状覆盖原 oj12、grid8192、长序列和多头，GPU 工作串行。

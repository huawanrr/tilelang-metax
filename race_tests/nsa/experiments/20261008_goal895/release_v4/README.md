## 改动与适用范围

以下均要求默认调参、`G = HQ/H = 16`；`grid = B * H * T`。
显式调参保留原路径，新的分派标志进入编译缓存键。缓存只保存编译产物。

| 路径 | 条件 | 改进 |
|---|---|---|
| 小 S1 直接读取 | BS16、完整块；D32/grid≤192；D64/grid≤256，且 grid≤128 或 T≥128 | K/V 直接装入 MMA 寄存器布局，shared 与同步均为零；D32 延后归一化，D64 提前归一化 |
| 中小 D128 | S1/BS16、完整块、H1、128<grid<768 | 先验证原始块号，成对读取完整块；自然指数与标量 FP16 转换 |
| 中型 D64 | S1/BS16、完整块、T≥128、512≤grid<2304 | 合并 Q/O 访存；自然指数后应用有效元素条件，保留原 shared 布局与七处 wave 同步 |
| 短 S2 | D64/BS16、T≥64、grid≤1024 | 自然指数、有限初始分数、指数后掩码与标量转换，支持尾块 |
| S4 单 kernel 流水 | D64/BS16、完整块、T≥128、H≤2、grid≤4096 | 分离 K/V shared tile，每个有效块两处同步；当前 V 就绪后提前将下一块读入普通寄存器，再计算当前 PV；输出合并写回 |
| S4 其他匹配范围 | D64/BS16、T≥128、768≤grid≤1536，未命中上项 | 已测 packed 路径；每次调用都执行打包，计时包含打包 |

八个实际 OJ 形状改变设备代码：1、2、3、4、10、11、13、14。
5、6、7、8、9、12 保留 10 月 7 日设备代码。
原有 49 个非分派函数保持，新增六个函数。公开接口签名保持。
原始块号在地址乘法前验证；新路径覆盖无效索引、零/负 scale、非因果、多头等边界。
没有异步拷贝、外部设备代码、Torch 计算或跨调用输入/结果缓存。
race 与 bounds 检查继续启用。

## 正确性、编译代码与资源核对

- 125 例独立 FP32 参考、TF32 关闭，工厂接口和 `run_kernel` 均通过；最大绝对误差 0.00390625。
- 55 个边界、45 个极端索引/scale 组合通过。
- 102 项调参对照与原版相同，含六项双方一致的原有不支持结果。
- 六个缓存调用顺序、36 次同地址输入更新及图回放、八项 RestrictedPython host 检查通过。
- 12 处标量转换的实际线程归属、完整覆盖和唯一性证明通过；成对读取、swizzle 与多头偏移证明通过。
- 开发/提交 AST 在去除注释与 docstring 后相等，静态提交检查通过。
- 最终 137 条计时记录、110 个不同配置与实际编译代码/参数相符；开发版与提交版完全一致。
- 另核对 218 条家族计时记录、105 个不同配置，最终组件与对应测量代码一致。

实际发射资源：小 S1 direct 为 0 bytes shared/0 barrier；D128 新路径为 4096 bytes/3 处 wave 同步；
中 D64 为 2048 bytes/7 处 wave 同步；S2 为 4096 bytes/3 处 block 同步；
新 S4 为一个 kernel、4096 bytes shared，循环中两处 wave 同步及最终输出两处。
S4 源代码静态计数的四处同步会随有效块循环执行，不能解释为每次调用仅同步四次。

分别采用的家族证据：v2 基础组件、S4 流水、v4 中 D64 数学改动。
S4 家族 70 组全部快于 10 月 7 日；中 D64 的额外数学改动相对 v3 有约 1% 的负样本，完整保留。
家族子集收益不能替代 109 例全量结果。

## 未采用的后续实验

大 S1 双 shared、多 wave CTA、D128 输出拆分、S8 扩展流水均未形成可靠改善。
小 D64 输出拆分无稳定收益，QK k_pack=1 明显回退。
IEEE 倒数在单种子热测出现约 3% 改善，但换种子及冷缓存存在回退，未合入；
rsqrt 平方倒数也未采用。`-prec-div=false` 与已有 fast-math 设置冗余，CPU IR 相同。
CPU 诊断生成的 C++/LLVM IR 没有加载执行或用于提交，也没有修改编译器、库或头文件。
所有原始正负数据和失败日志保留在研究目录。

## 变更

Q 读取后的一次 wave 同步使编译器保留 Q 与稀疏索引读取的先后顺序。
小 D128 同时采用完整块的直接 K/V 寄存器读取。

均限默认参数、S1、BS16、G16、完整块。D64 沿用 v4 的小 direct 范围；
D32 限因果、T≥64、grid≤64；D128 限 grid≤128。新分派进入编译缓存键。
只缓存编译产物；每次调用和图回放读取当前输入。

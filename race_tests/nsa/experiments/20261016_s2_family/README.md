## 最终候选

新增 `native_sparse_attention_short_list_oct8_wave_output_v15`，其函数体和编译
参数与筛查成功的输出方案相同。保留全部旧 builder，只在既有默认 S2 路径中，
H1/G16/D64/BS16、`seq_len >= 64`、完整块且 `256 <= B*H*seq_len <= 384`
时使用新增 builder；选择标志加入规范化缓存键。
两个公开入口、输入转换、checked adapter、数学表达式、FP32 字符串类型、
显式调参回退保持。每次调用读取当前输入，没有张量或地址缓存。

最终 17 个家族形状 × 两种子的 24 次 A/B/A 热测全部为正，平均
**1.08551793×**；同源控制 1.00021724×。
OJ10 两种子为约 **1.060219× / 1.038725×**。
15 个家族形状 × 两种子的冷缓存测量平均 **1.06110128×**，每行 8 轮 × 48 次，
每次公开调用前冲刷 256 MB，再累计实际设备 kernel 时间。
OJ10 冷测为 **1.050601× / 1.063398×**。

最终冷测有一行负值，未丢弃：B1/T304、seed0 为 **0.99961583×**，
6.938667 → 6.941333 µs，接近持平；seed61 为 1.00924499×。
没有重跑并挑选更快值，也没有把本地时延折算成新的官方总分。
